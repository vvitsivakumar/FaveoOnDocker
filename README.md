# Faveo Docker Deployments

<img src="https://thumb.wikimedia.org/wikipedia/commons/thumb/4/4e/Docker_%28container_engine%29_logo.svg/960px-Docker_%28container_engine%29_logo.svg.png?utm_source=commons.wikimedia.org&utm_campaign=index&utm_content=thumbnail" alt="Docker" width="260"/>

Install Faveo on your own server with Docker - with **one command**.
The installer sets up everything for you: web server, database, cache, SSL and Faveo itself.

| I want to... | Use | License needed? |

Click the product name to open its guide.

---

## Why use these installers?

- ⚡ **Easy** - one command, or just answer a few questions.
- 🔒 **SSL included** - free Let's Encrypt, self-signed, or your own paid certificate.
- 🔑 **Secure** - strong passwords are created and saved for you.
- 🐧 **Works on most Linux servers** - Docker is installed for you if missing.
- ↩️ **Safe** - if something goes wrong, the changes are undone automatically.
- 💾 **Backup and remove** - built-in commands to back up or uninstall.

---

## What do I need?

- A Linux server with `sudo` access
- A domain name pointed to the server
- A license code and order number (Helpdesk and Network Discovery only)
